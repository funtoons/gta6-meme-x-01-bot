Entry for make.fun's "Post a GTA 6 meme on X" bounty. The meme is a skeleton gamer who has been waiting for GTA 6 since 2013 — so long he turned into a skeleton, controller still in hand, the TV stuck on "LAUNCHING... 99%" — with the make.fun ghost floating beside him, star coin in hand, against a Vice City sunset. The picture was posted on X from a public account, and this repository hands in that post's address.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

That copies `POST.json` to `out/POST.json`, naming the X post that is the entry.
